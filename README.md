# Flipke d'n Dappere

In 1386 richtte de Brabander Filips de Stoute (Brabants: Flipke d'n Dappere) in Rijsel een Raadkamer voor financiële en juridische aangelegenheden voor Vlaanderen, Artesië, Antwerpen en Mechelen in. Dit bovenregionale orgaan was een kiem waaruit later de Staten-Generaal van de Nederlanden zou groeien.
